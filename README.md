## 🚀 Featured projects

### 🏥 EMR & Patient Intake Platform

A production Electronic Medical Record platform I work on at Corunit Media Corp, covering patient intake, clinical documentation, scheduling, billing and practice administration for clinic teams with different roles.

- **Problem:** clinic work runs through connected steps (intake, visit notes, follow-ups, billing). Spread across separate tools, information gets re-entered and it becomes hard to answer who changed a record and when.
- **What I did:** I built patient intake workflows with complex form data, SOAP-note documentation, appointment scheduling, and billing and superbill workflows. I developed REST APIs with Django REST Framework, implemented authentication and role-based access control, worked on audit logging and data migration, and handle production deployment and debugging on AWS. The platform is a team effort; these are the parts I worked on.
- **Stack:** Python, Django, Django REST Framework, JavaScript, HTML/CSS, Bootstrap, SQLite, AWS, Nginx
- **Status:** in production (Mar 2025 – present). The code is confidential.
- 📖 [Read the EMR case study](https://sajidkalam.com/projects/emr-patient-intake-platform)

### 📦 Lanexis Customer Portal

A B2B customer portal I built for Lanexis, bringing together users, projects, dashboards, reporting, notifications, and order and shipment data the client kept in internal Google Sheets.

- **Problem:** customers and staff needed controlled access to the right slice of that spreadsheet data, without anyone working inside the spreadsheets directly.
- **What I did:** as lead full-stack engineer and system designer, I planned the product, designed the architecture, built the Django and DRF backend, worked on the React Native / Expo app, integrated the Google Sheets API with manual synchronisation, added audit tracking for logins and create, update and delete actions, deployed it on AWS, and was the client's main technical contact.
- **Stack:** Django, Django REST Framework, React Native, Expo, PostgreSQL, Google Sheets API, AWS EC2, RDS and S3, Nginx, Gunicorn
- **Status:** completed and deployed (client project)
- 📖 [Read the Lanexis case study](https://sajidkalam.com/projects/lanexis-customer-portal)

### 🧠 Quiz Hub: AI-Assisted Student Portal

An academic Django project I built where teachers and students generate quizzes on a topic, take them and track their attempts.

- **How it works:** I used a custom user model with student, teacher and admin roles, with access enforced through a decorator and middleware. Quiz generation tries Google Gemini first, falls back to OpenAI, and finally to a rule-based generator, so the feature degrades instead of failing.
- **Stack:** Python, Django, SQLite, Bootstrap, Google Gemini API, OpenAI API
- 💻 [Source code](https://github.com/SajidKalam-byte/AI-Powered_Quiz_Generator) · 📖 [Case study](https://sajidkalam.com/projects/quiz-hub)

### ♟️ Chess for Two

A two-player chess game I built for the browser, with no application server or database. One player shares an invite link, and moves and chat travel directly between the two browsers over PeerJS (WebRTC).

- **How it works:** I wrote the chess rules (legal moves, castling, en passant, promotion, checkmate and stalemate) from scratch in plain JavaScript, without a chess library.
- **Stack:** JavaScript, HTML, CSS, PeerJS, WebRTC

## 🛠️ Engineering approach

These are the principles I work by, and you can see them in the projects above:

- **Understand the workflow before the code.** Different roles see the same record differently, so mapping who does what comes before designing models and endpoints.
- **Enforce rules on the server.** Permissions and validation live in the backend, so they apply whether a request comes from a page or an API call.
- **Make changes traceable.** Audit trails, careful migrations and reversible changes make production systems easier to trust and debug.
- **Stay with it after launch.** Deployment, watching features in real use and fixing client-reported bugs are part of the job.
- **Be honest about limits.** My case studies say where results stop applying, such as why an accuracy figure can mislead on imbalanced data.
